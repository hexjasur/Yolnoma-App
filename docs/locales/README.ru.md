**Yolnoma-App** объединяет практические инструменты для разработчиков, анализ сети, медиа-утилиты, обработку изображений, рабочие пространства ИИ и интеграции со Steam в одном нативном десктопном приложении. Вместо переключения между десятками вкладок браузера вы можете использовать единое рабочее окружение на базе [Tauri](https://tauri.app/).

> Yolnoma-App — независимый проект Джасурбека Хайдарова под брендом JK Software. Он не связан, не одобрен и не спонсируется Valve Corporation или Steam.

# Почему Yolnoma?

Большинство повседневных инструментов разбросаны по вкладкам браузера, отдельным скриптам и однозадачным программам. Yolnoma построена вокруг другой идеи — универсального десктопного инструментария, который растет вместе с вашими задачами.

- **Одно приложение, множество задач** — утилиты для разработки, сети, медиа, изображений, ИИ, файлов и игр в одном месте.
- **Нативная десктопная основа** — React и TypeScript в интерфейсе, Tauri v2 и Rust на системном уровне.
- **Удобная навигация по рабочим областям** — инструменты сгруппированы по вкладкам и разделам вместо перегруженной одной панели.
- **Локальное хранение данных** — конфигурация аккаунта и сессии ИИ-чата хранятся на устройстве пользователя; внешние запросы к ИИ направляются только выбранному провайдеру.
- **Активное развитие** — с каждым обновлением добавляются новые утилиты, интеграции и улучшения интерфейса.

## Требования

Перед запуском или сборкой Yolnoma-App локально убедитесь, что система удовлетворяет требованиям:

### Операционная система

- **Windows 10 / 11** (64-bit) рекомендуется для полной поддержки всех системных функций.

### Инструменты разработки

1. **[Bun](https://bun.sh/) (v1.4+)** или **Node.js (v18+)**:
   - Используется для управления зависимостями фронтенда и скриптов.
2. **[Rust Toolchain](https://www.rust-lang.org/tools/install)** (`rustc`, `cargo`):
   - Tauri v2 требует Rust для компиляции бэкенда (`stable` канал).
   - Установка через `rustup`:
     ```bash
     rustup default stable
     ```
3. **[Tauri v2 Prerequisites](https://v2.tauri.app/start/prerequisites/)**:
   - **Windows:** Требуется **Microsoft Visual Studio C++ Build Tools** (компонент "Desktop development with C++") и **WebView2 Runtime**.

## Быстрый старт

```bash
# 1. установка зависимостей
bun install

# 2. создание локального .env файла
cp .env.example .env

# 3. запуск приложения в режиме разработки
bun run tauri dev
```

## Конфиденциальность и безопасность данных

Диалоги ИИ-чата сохраняются **локально** на вашем компьютере:

```text
%LOCALAPPDATA%\Yolnoma\accounts\<user-id>\ai-chat\sessions\<session-id>.json
```

При отправке запроса промпт и контекст передаются напрямую выбранному провайдеру (например, **OpenRouter**). Данные не передаются на серверы Yolnoma, и Yolnoma не навязывает общие ключи доступа.

Полная информация о политике безопасности доступна в [SECURITY.md](../../SECURITY.md).
