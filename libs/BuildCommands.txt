## SteamUtility archive build (Dotnet SDK Required v8.0+)

Windows PowerShell’da repository root’dan canonical build script’ni ishga tushiring:

```powershell
./scripts/build-steam-utility.ps1 -Configuration Release -Runtime win-x64
```

Script publish output’ni tekshiradi, `SteamUtility.exe` va `steam_api64.dll` mavjudligini tasdiqlaydi,
so‘ng barcha dependency’larni `src-tauri/resources/yolnoma_steamutility.dat` ZIP archive’iga joylaydi.
Tauri release build ham aynan shu archive’dan foydalanadi.

To‘g‘ridan-to‘g‘ri publish qilish kerak bo‘lsa:

```
dotnet publish -c Release -r win-x64 --self-contained true
```

## Legacy publish folder

```text
bin\Release\<target-framework>\win-x64\publish\
```
